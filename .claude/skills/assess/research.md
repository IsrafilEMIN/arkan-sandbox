# Research

Investigate a question against high-trust primary sources and capture the findings.

Spin up a **background agent** to do the research, so you keep working while it reads.

Its job:

1. Investigate the question against **primary sources** (official docs, source code, specs, first-party APIs), not a secondary write-up of them. Follow every claim back to the source that owns it.
2. Label every claim **first-hand** (the official source, or a named practitioner describing their own setup) or **recap** (someone else's summary). A recap is a lead to the first-hand source, not evidence.
3. For fast-moving tools (AI harnesses, models, CLIs, provider plans), check the current docs, changelog and release notes today, and write the version and date you checked. Training knowledge of these tools is stale by default.
4. Write the findings to a single Markdown file, citing each claim's source and its label.
5. Save it where the repo already keeps such notes; match the existing convention, and if there is none, put it somewhere sensible and say where.
